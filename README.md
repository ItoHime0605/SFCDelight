# 鹹酥雞樂事 — 第三輪原始碼雛形

Minecraft 1.21.1 / NeoForge / Java 21，版本 `0.1.2-alpha`。

本輪：16 種物品註冊、原創 32×32 像素物品圖、台灣繁體中文、6 份工作台配方、雙鹽標籤、放血刀擊殺豬／雞時背包玻璃瓶兌換血瓶的事件程式碼。

**重要：尚未編譯、尚未測試。** `build.gradle` 是開發起點，NeoForge ModDevGradle 版本與事件 API 仍需實際 Gradle 驗證；可能需調整 `LivingDeathEvent`、`SwordItem` 與物品註冊呼叫。尚未實作 Farmer's Delight 烹飪鍋、砧板、油炸台、GUI 或完整食物數值。僅已確認相關前置 JAR 內的部分物品資源存在，不能把資源存在等同於完整遊戲驗證。
