# 鹽酥雞攤車：開放式斜面重製（0.2.66-alpha）

本次 **只修改攤車**，不更動炸爐、脫油機、準備台、食物配方或持有物品資料。

- 展示區不再是三層架或有玻璃的展示箱；兩個展示方塊拼成 **一片前低後高的 45° 斜面**，整面依深度與左右位置劃分 **4 × 3 = 12 個**展示格。
- 模組啟動時不預先在展示格放入食材。參考圖上的食材只是配置示意；真正顯示的是玩家安裝的展示塑膠框及真實存入的食材。
- 點選座標由原本垂直高度分列，改為前後深度分列，並支援點選斜面向上的可碰觸區域；依方位旋轉四向。
- 移除展示模型所有玻璃。招牌、支架、木櫃、調味罐、籃子功能維持。
- 棚布沿顧客方向 **突出半格（8 像素）**，棚內前緣使用固定式細長燈管；圖上的後方燈柱、前方燈籠不是這台攤車的一部分，不製作成方塊。
- 對應展示區的兩個方塊繼續提供遊戲內的 12 級照明（既有燈光機制）。
- 攤車外觀使用現有 **128 × 128** 的木頭、黃銅與金屬材質，保留 Minecraft／Delight 感。

此版本已加入原始碼與自動回歸驗證，實際遊戲視角、點選及模型渲染仍需最後實機驗收，非正式版。

## 0.2.69-alpha｜棚頂招牌、帆布垂邊與完整照明

- 刪除左側檯面下方的舊招牌，將唯一正式招牌搬到棚頂中央，以兩個分段模型與前面 UV 左右各半拼接，避免招牌文字重複。
- 紅白棚沿增加兩段式像素下垂輪廓；顧客方向保持突出半格，背景燈柱和正面吊燈不納入。
- 三個上層方塊均維持 12 級發光方塊，並將固定燈管模型關閉明暗面陰影。
- 手持道具同步加入棚頂立體招牌及帆布垂邊。展示區不放預設食材、不裝玻璃，維持空的 12 個位置，僅在玩家真正放入塑膠框時顯示。
- 裝飾招牌延伸至原本兩格高結構上方約半格；不新增碰撞或儲存欄位。低矮天花板可能產生視覺穿模，待遊戲實測。
- 本輪為模型與靜態驗證修改，尚未完成 NeoForge 建置及遊戲渲染驗收。
