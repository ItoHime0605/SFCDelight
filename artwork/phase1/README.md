# SFCDelight Phase 1 — Visual Redesign

Original 32×32 transparent pixel sprites for 12 flat inventory items, plus a consistent 17-color family of genuine 3D slatted plastic baskets.

`plastic_basket_concept.png` is the 13th design reference. In-game baskets deliberately remain **3D** (shared model `assets/sfcdelight/models/item/plastic_basket_base.json`), so the rear rack on the cart keeps its physical baskets. All 16 dye variants reuse the shared shape with their original colored textures.

No equipment recipes, inventory components, food values, or other gameplay code were changed in this art pass.
