# 第六輪｜常見炸物美術精修

Minecraft 1.21.1／NeoForge 的《鹹酥雞樂事》資源檔精修。

這輪重新繪製 **11 款 32×32 透明 PNG**：鹹酥雞丁、酥炸魚丁、薯條、地瓜薯條、炸豆干、千層豆腐、炸鴨血、米血糕、酥炸魷魚腳、魷魚球與甜不辣。

- 酥炸食材統一使用暖金黃色系，並保留陰影及不規則粉衣邊緣。
- 魚丁露出淺色魚肉；地瓜薯條保留紫色外皮；千層豆腐保留切面層次。
- 血製品採深紅褐色，不與一般炸物混淆；魷魚腳及魷魚球保留明顯不同的外型。
- 遊戲中的物品 ID、配方、飽和度、特殊效果、GUI 及設備功能全部維持原狀。

只有美術素材與自動驗證程式更動，不應單獨當作最終版交付。
