## 本次實際改動

- **13 種原本 16×16 的共用方塊材質改為真正有細節的 128×128 RGBA PNG**，不是單純把小圖放大：木紋與木節、霧面金屬刷紋與鉚釘、黃銅扣件、紅白織布棚面、瓷面與搪瓷收邊、油面水波、塑膠格紋和洗手槽水紋。
- **14 個既有方塊模型檔增加真實的立體小零件**：攤車下櫃立體五金、招牌鉚釘、七種油量顯示狀態的金屬前緣、脫油機散熱格柵、準備台下櫃收邊。
- 不改物品 ID、配方、NBT、方塊狀態、12 格食材判定、炸籃動畫、脫油機食物渲染及兩個準備台的操作。
- 保留原有 32×32 cutout 透明玻璃，不以不透明高解析材質遮蔽展示食材。

新增 `validate_phase8_equipment_art.py`，確認 13 張材質是正確的 128×128 PNG、模型凹凸確實在世界方塊模型中、油槽仍開放、攤車旋轉狀態與玻璃設定不變。仍需最終 Minecraft 實機檢查實際光影和模型重疊。
